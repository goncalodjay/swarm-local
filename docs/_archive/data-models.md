# Data Models

La carpeta `data-models` contiene archivos que definen los esquemas y estructuras de datos utilizados en el proyecto. Estos modelos describen cómo se organizan y relacionan los datos, permitiendo una representación clara y consistente de la información.

## Archivo `opencode-models.tsv`
Este archivo (tablas de valores separados por tabulaciones) estaba diseñado para listar y describir los modelos de datos disponibles. Cada fila representaba un modelo, incluyendo detalles como su nombre, propósito y campos asociados. Por ejemplo:
```
nombre	modelo	descripcion
Usuario	usuario	Representa a un usuario del sistema con campos como id, nombre y email.
```
Sin embargo, el archivo no fue encontrado, lo que indica que podría estar faltando o no haberse completado. Se recomienda verificar su existencia o crearlo para documentar los modelos de manera estructurada.

## Uso
Los modelos de datos se utilizan para:
- Definir la estructura de bases de datos.
- Validar la entrada de datos en aplicaciones.
- Facilitar la comunicación entre componentes del sistema.
